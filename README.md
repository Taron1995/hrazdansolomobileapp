# Ani Hrazdan — ներքին կառավարման ծրագիր

ASP.NET Core 8 վեբ հավելված (Razor Pages + SignalR + SQLite)՝ հարմարեցված հեռախոսի համար (կարելի է ավելացնել հեռախոսի գլխավոր էկրանին որպես հավելված)։

## Գործարկում

```bash
cd UGeekStore
dotnet run
```

Բացել http://localhost:5000 ։ Առաջին մուտքը՝ `admin@local` / `admin123` (փոխել `appsettings.json` → `Seed`)։
Ադմինը «Աշխատակիցներ» բաժնում ավելացնում է գանձապահներին, մենեջերներին, հրուշակագործներին և առաքիչներին՝ իրենց Gmail հասցեներով։

## Կարգավորումներ (`UGeekStore/appsettings.json`)

- **Gmail մուտք**․ `Authentication:Google:ClientId/ClientSecret` (Google Cloud Console → OAuth client, redirect URI՝ `https://<domain>/signin-google`)։
- **Google Sheet**․ `GoogleSheets:SpreadsheetId` և `ServiceAccountKeyPath` (service account JSON ֆայլ)։ Աղյուսակը կիսել service account-ի email-ի հետ։ Ստեղծել թերթեր `Դրամարկղ` և `Կասսայի փակում` անուններով։
- **WhatsApp**․ `Messaging:WhatsApp:Token/PhoneNumberId` (Meta WhatsApp Business Cloud API)։ Առանց դրա ծրագիրը տալիս է wa.me հղումներ՝ ձեռքով ուղարկելու համար։
- **SMS**․ `Messaging:Sms:Url/ApiKey/Sender` (ցանկացած HTTP SMS gateway)։
- **Vivacell / PBX**․ `Telephony:ApiKey`։ Բաց թողնված զանգերը ուղարկվում են `POST /api/missed-calls` հասցեով, header `X-Api-Key`, body `{"phone":"091123456","calledAt":"2026-11-11T10:00:00+04:00"}`։ Vivacell-ի հետ պետք է ճշտել, թե ինչ ձևով կարող են փոխանցել տվյալները։
- **Ժամային գոտի**․ `App:TimeZone` (լռությամբ `Asia/Yerevan`)։ Բոլոր ամսաթվերը վերցվում են սերվերից, ոչ թե հեռախոսից։ Հեռախոսի ժամը պահվում է առանձին՝ ստուգման համար։
